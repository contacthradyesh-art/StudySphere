HOW TO APPLY
------------
1. Extract this zip.
2. Copy the "src" folder into your project root, letting it merge/overwrite.
3. If you haven't already: delete this folder manually (not touched by
   the zip) --  src/app/(dashboard)/dashboard/bushido/
4. In VS Code terminal:
       git add .
       git commit -m "English Lab: add Vocabulary, Grammar Quiz, Quick Tools"
       git push
