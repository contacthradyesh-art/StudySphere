HOW TO APPLY
------------
1. Extract this zip.
2. Copy the "src" folder from the extracted zip into your project root,
   letting it MERGE/overwrite — your file manager or VS Code will ask
   "replace these files?" for the 3 changed ones. Say yes.
3. DELETE this folder manually (not included in the zip, since deleting
   can't be done by adding files):
       src/app/(dashboard)/dashboard/bushido/
4. In VS Code terminal, run:
       git add .
       git commit -m "Remove Bushido, add English Communication Lab"
       git push
